# Quail Digital ISM System (Installation & Service Management)

Interactive enterprise UI prototype for **Quail Digital's Installation & Service Management (ISM) System**, modeling a **Zoho Creator Enterprise (Premium Tier)** application with **Kendo UI** widgets.

## Live GitHub Pages
This project is configured for instant deployment to GitHub Pages. Open `index.html` in any browser or visit your GitHub Pages URL:
`https://<your-username>.github.io/<your-repo-name>/`

## Key Modules
- **Role Switcher**: Real-time switching between Project Management (Sarah Jenkins), Field Subcontractor (Mike Vance - Apex Telecom), and Customer Service (Elena Rostova).
- **Customer & Store Management**: Multi-branch stores, 360° customer history drawer, and guided intake form.
- **Product & Package Catalogue**: Pro9 headset models, Pro10 base stations, and enterprise bundles with BOM.
- **Subcontractor Master & Smart Lookup**: Contractor skills, coverage regions, and workload matching.
- **Installation Job Lifecycle**: Automated state machine, calendar scheduler widget, and quality verification gate with rejection workflows.
- **Field Installation Record**: Mobile-optimized stepper, Kendo integrations grid, mandatory checklist gates, and annotated photo evidence.
- **Support Ticket Management**: Dual resolution paths (On-Site Field Visit vs. In-House Repair RMA bench tracker) with versioned document attachments.
- **Notifications & Email Log**: Notification bell dropdown preview + slide-over transactional email alert inbox.
- **Dashboards & Embedded Analytics**: KPI cards, native SVG bar/donut charts, and Customer Service priority heat map.
- **Bulk Import Wizard**: 4-step CSV import with column mapping and smart duplicate detection.
